# Java-Swing-Projects

Two desktop applications I built  in Java with a Swing graphical interface, to practise and test my programming skills.

## 1. Stokvel Contribution Tracker

A burial society app for a treasurer to record member contributions and track the total pot, built with Java Swing and Object-Oriented Programming.

### Features
* Actions menu (JMenuBar) for recording contributions
* Shows each contribution received and the running total pot
* Handles invalid input with try-catch exception handling

## 2. Retail Inventory Management System

A stock management app for a clothing store that lets the user add, view, update and delete products, with a log of every action.

### Features
* Captures Product ID, Name, Size, Category, Price and Quantity
* Add, View, Update, Delete and Exit buttons
* Inventory log that records each action
* Layout managers (JPanel and GridLayout) for the interface
* Converts user input with Double.parseDouble and Integer.parseInt
* Handles invalid entries with error handling
